# 温泉AIコンシェルジュ — 営業デモ

旅館・温泉施設さま向け、多言語コンシェルジュのデモページです。

- **日本語 / 한국어 / English / 繁體中文** の4言語に対応
- 浴場入口の**温泉分析書**（温泉法第18条に基づく掲示）を読み取り、
  お客様がご登録された体調と照らし合わせて母国語でご説明します
- タトゥーの可否、入浴の作法、館内のご案内

## ご注意

**本ページはデモです。** AIの応答はサンプル固定であり、実際の生成は行いません。
登場する「湯の音旅館」は**架空の施設**で、実在の旅館の情報は一切含みません。

掲示内容の翻訳・整理を行うものであり、医学的な診断ではありません。
